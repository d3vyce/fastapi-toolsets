# `security`

Here's the reference for the authentication helpers provided by the `security` module.

You can import them directly from `fastapi_toolsets.security`:

```python
from fastapi_toolsets.security import (
    AuthSource,
    BearerTokenAuth,
    CookieAuth,
    OAuth2Auth,
    OpenIDAuth,
    MultiAuth,
)
```
