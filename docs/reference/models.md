# `models`

Here's the reference for the SQLAlchemy model mixins provided by the `models` module.

You can import them directly from `fastapi_toolsets.models`:

```python
from fastapi_toolsets.models import (
    EventSession,
    ModelEvent,
    UUIDMixin,
    UUIDv7Mixin,
    CreatedAtMixin,
    UpdatedAtMixin,
    TimestampMixin,
    listens_for,
)
```
